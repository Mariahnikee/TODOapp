
# AGENTS.md

## Project Overview
A responsive Todo List application built for HNG Internship 15 Stage 1.

## Tech Stack
- React
- Vite
- JavaScript
- CSS
- Browser localStorage

## Commands
- `npm install` — install dependencies
- `npm run dev` — start development server
- `npm run build` — create production build
- `npm run lint` — run ESLint, if configured

## Conventions
- Use functional React components and hooks.
- Keep components readable and focused.
- Use semantic HTML and accessible labels.
- Keep styles in CSS files.
- Avoid unnecessary dependencies.

## Important Constraints
- Do not add secrets or credentials to the repository.
- Do not overwrite unrelated files.
- Test changes and run the production build before submitting.
- Keep task data persistent across page refreshes.
